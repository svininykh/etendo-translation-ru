# Etendo ERP Translation Russian
Перевод Etendo ERP на русский язык для Казахстана

Etendo ERP — современная гибкая ERP-платформа для комплексного управления предприятием, объединяющая продажи, закупки, склад, производство, финансы и бухгалтерский учет в единой информационной системе.

Платформа построена по модульному принципу: стандартную функциональность можно расширять готовыми модулями, локализацией и собственными разработками без изменения ядра системы.
